# Slot Machine

Proyecto inicial - Ciclo 1
Desarrollo Orientado por Objetos [DOPO-POOB]

## Descripción

Desarrollo de un simulador de máquina tragamonedas en Java utilizando BlueJ. El proyecto reutiliza componentes gráficos del proyecto `shapes` y su diseño UML fue realizado utilizando Astah.

## Organización del repositorio

El repositorio se encuentra dividido en las siguientes ramas:

### `codigo`

Contiene la implementación del simulador desarrollada en Java y los archivos necesarios para trabajar el proyecto en BlueJ.

### `astah`

Contiene el diseño UML del proyecto realizado en Astah, incluyendo el diagrama de clases y los diagramas de secuencia de los métodos construidos de la clase principal `SlotMachine`.

### `retrospectiva`

Contiene el análisis general del desarrollo del proyecto: mini-ciclos realizados, estado del proyecto, tiempo invertido, logros, problemas técnicos, trabajo en equipo, prácticas XP y referencias utilizadas.

### `main`

Contiene la descripción general y organización del repositorio.
